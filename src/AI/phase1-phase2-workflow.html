Sơ đồ thể hiện các actors (Parent, Teacher, Child) và cách họ tương tác với hệ thống qua các Phase.

👨‍👩‍👧 Parent (Phụ huynh)

  • Tạo story cho con
  • Review và approve content
  • Quản lý child profile
  • Xem lịch sử story đã tạo

👩‍🏫 Teacher (Giáo viên)

  • Tạo story cho học sinh
  • Review content trước khi phát hành
  • Quản lý nhiều child profiles
  • Xem báo cáo học tập

👶 Child (Trẻ em)

  • Đọc story đã được approve
  • Nghe audio narration
  • Xem illustrations
  • Làm quiz và discussion

    Note over Parent,DB: Phase 1: Input & Guardrail

    Parent->>FE: Submit creative input
    FE->>API: POST /api/stories/generate
    API->>API: Validate authorization
    API->>API: Resolve effective context
    API->>API: Input guardrail check
    API->>DB: Save Story draft + Request
    API-->>FE: 202 Accepted (Story ID)
    FE-->>Parent: Hien thi Dang xu ly...

    Note over Parent,DB: Phase 2: AI Outline Generation (Background)

    Worker->>DB: Poll OutlinePending job
    Worker->>API: Get accepted input + snapshot
    API->>AI: Generate outline (Title, Opening, Development, Ending)
    AI-->>API: Outline JSON
    API->>DB: Save StoryVersion (Outline)
    API->>DB: Update Story: OutlineReview
    API-->>FE: Notify Outline ready
    FE-->>Parent: Can review outline

    Note over Parent,DB: Phase 2: Human Review

    Parent->>FE: Open outline review
    FE->>API: GET /api/stories/{id}/outline
    API-->>FE: Outline data
    FE-->>Parent: Hien thi outline

    Parent->>FE: Edit/Regenerate/Approve
    FE->>API: PUT /api/stories/{id}/outline
    alt Edit hoac Regenerate
        API->>Worker: Create RegenerateOutline job
        Worker->>AI: Generate new outline
        API-->>FE: Outline da cap nhat
    else Approve
        API->>DB: Update StoryVersion (ApprovedAt)
        API->>DB: Create ContentPending job
        API->>DB: Update Story: ContentPending
    end

    Note over Parent,DB: Phase 3: AI Content Generation (Background)

    Worker->>API: Poll ContentPending job
    API->>AI: Generate full story content
    AI-->>API: Story content (paragraphs)
    API->>AI: Generate vocabulary, quiz, discussion
    AI-->>API: Artifacts
    API->>DB: Save StoryVersion (Content)
    API->>DB: Update Story: ContentReview
    API-->>FE: Notify Content ready
    FE-->>Parent: Can review content

    Note over Parent,DB: Phase 4: Human Content Review

    Parent->>FE: Open content review
    FE->>API: GET /api/review/{storyId}
    API-->>FE: Full review package
    FE-->>Parent: Hien thi content + vocab + quiz

    Parent->>FE: Review step-by-step
    FE->>API: PUT /api/review/{storyId}/step
    API->>DB: Update review progress

    Parent->>FE: Edit/AI Regenerate/Approve
    alt Edit
        API->>DB: Create new StoryVersion (ManualEdit)
        API-->>FE: Da luu chinh sua
    else AI Regenerate
        API->>AI: Generate new artifact
        API->>DB: Save proposal
        API-->>FE: De xuat AI moi
    else Approve
        API->>DB: Update StoryVersion (ApprovedAt)
        API->>DB: Create MediaPending job
        API->>DB: Update Story: Approved
    end

    Note over Parent,DB: Phase 5: Media Generation (Background)

    Worker->>API: Poll MediaPending job
    API->>API: Parse content to Blocks
    API->>AI: Segment scenes
    loop For each scene
        API->>AI: Generate illustration
        AI-->>API: Image bytes
        API->>AI: Generate TTS audio
        AI-->>API: Audio bytes
        API->>API: Upload to Supabase Storage
        API->>DB: Save MediaAsset records
    end
    API->>DB: Update Story: Ready
    API->>DB: Set ChildVisibleAt = now
    API-->>FE: Notify Story ready!

    Note over Child,DB: Child Reads Story

    Child->>FE: Open story library
    FE->>API: GET /api/stories/ready?childId={id}
    API-->>FE: Ready stories list
    FE-->>Child: Hien thi stories

    Child->>FE: Select story
    FE->>API: GET /api/stories/{id}
    API->>DB: Get StoryVersion + MediaAssets
    API->>API: Generate signed URLs (expire 1h)
    API-->>FE: Story data + signed media URLs
    FE-->>Child: Display story with illustrations + audio

    Child->>FE: Play TTS narration
    FE->>FE: Play audio sequentially
    Child->>FE: Take quiz
    FE->>API: POST /api/quiz/submit
    API->>DB: Save quiz results

Bảng tương tác theo Phase

Phase Actor Action System Response Backend Process
P1 Parent/Teacher Submit creative input 202 Accepted, polling status Input guardrail → Save draft
P2 System AI generates outline (async) Notify when ready Worker → LLM → Save version
P2 Parent/Teacher Review outline Show outline + actions GET outline, PUT decision
P3 System AI generates content (async) Notify when ready Worker → LLM → Save content
P4 Parent/Teacher Review content package Show story + vocab + quiz GET review package
P4 Parent/Teacher Step-by-step review Update progress PUT review step
P4 Parent/Teacher Edit/AI regenerate/Approve Show result Create version or approve
P5 System Generate media (async) Notify when ready Worker → AI → Supabase
P5 Child Read story Display with media GET story + signed URLs
P5 Child Play audio narration Audio playback Client-side audio
P5 Child Take quiz Show results POST quiz submit

🎯 Kiến trúc tổng quan

  • Background Worker polling (2s interval)
  • Concurrency token lease (4 phút)
  • Immutable snapshot cho AI prompts
  • Human approval gate trước Phase 5
  • Story continuity: blocks → scenes → media

Story Continuity: Block → Scene → Media

Đảm bảo mỗi illustration và audio được sinh từ đúng đoạn text gốc của story, duy trì sự hợp nhất giữa nội dung và hình ảnh.

Layer Entity Key Fields Continuity Mechanism
1. Content StoryVersion.Content Canonical story text Immutable, không bị rewrite
2. Blocks StoryBlock BlockId, StartOffset, EndOffset Stable IDs (P1, P2, P3...), exact character ranges
3. Scenes StoryScene SceneIndex, TextRangeStart, TextRangeEnd, SceneText Coverage validator đảm bảo full content được cover
4. Media MediaAsset StorySceneId, Type, StoragePath GeneratedMedia chứa exact scene text + visual description

Cơ chế bảo đảm tính đúng

Snapshot authority

Phase 2-5 đọc snapshot/input bất biến, không dùng profile đang thay đổi.

Idempotency

Submit, retry, regenerate và approve có operation key.

One active operation

Filtered unique index chặn hai job cùng operation trên Story.

Lease recovery

Job bị bỏ dở được reclaim sau khi lease hết hạn.

Story transaction lock

Edit và approve không thể cùng chấp nhận một version cũ.

Human approval gate

Không story nào đến tay trẻ mà chưa qua Phase 4 approval.

Scene coverage validation

Validator đảm bảo blocks cover đầy đủ content, không trùng lặp.

Stale result detection

AssertFresh kiểm tra job/version/context còn fresh trước mỗi persist.

Fail-closed evaluators

Media evaluator fail-closed: unconfigured = explicit failure, không uncertain.

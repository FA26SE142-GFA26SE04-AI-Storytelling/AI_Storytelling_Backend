Test API Luồng 1 — User và chủ hồ sơ trẻ

Checklist test tay cho thay đổi bỏ Supervisor, đổi role Parent thành User và xóa tài khoản. Chọn Pass/Fail và ghi chú; tiến độ được lưu trong trình duyệt.

Chuẩn bị

Môi trường: Dùng database test đã áp dụng migration RemoveSupervisionAndRenameParentRole. File migration đã được tạo trong repo, nhưng chưa được apply lên database nào. Trên DB cũ, tài khoản hiện có vẫn mang role Parent nên kết quả role sẽ không đúng checklist này.

Dữ liệu cần có

  1. Hai tài khoản active role User: A là chủ hồ sơ trẻ, B là người khác. Lấy access token và refresh token từ POST /api/v1/Auth/login.
  2. Một hồ sơ Draft của A và một hồ sơ Active của A đã có Learning Profile, Safety Policy và consent. Ghi lại childProfileId.
  3. Một truyện riêng của hồ sơ Active đủ trạng thái để thử các API truyện. Các API AI, review, roadmap, cộng đồng còn phụ thuộc trạng thái truyện, chính sách, quota và consent.
  4. Một tài khoản test riêng C cho ca xóa tài khoản; đừng dùng A/B hoặc dữ liệu muốn giữ.
Quy ước: Thay các giá trị <...> bằng ID, mật khẩu hoặc token thực trong Swagger/Postman. Trang này chỉ tạo hướng dẫn; không gửi request, không lưu token. Với các API có điều kiện nghiệp vụ, ca âm cần kiểm tra không đọc/sửa được dữ liệu của người khác; mã lỗi có thể là 403 hoặc 404 tùy endpoint.

1. Chuẩn bị và quy ước

  • Chạy API (Swagger hoặc Postman). Đặt biến BASE = địa chỉ API, ví dụ https://localhost:5001.
  • Cần hai loại token khác nhau: PARENT_TOKEN (đăng nhập tài khoản phụ huynh, role User) và CHILD_TOKEN (token của trẻ, lấy ở bước handover). Token của trẻ không gọi được API phụ huynh và ngược lại.
  • Mọi response có dạng { "success": ..., "data": ..., "message": ... }. Lỗi nghiệp vụ trả mã 400/403/404/409 kèm message.
  • Database cần đã áp migration AddStorySummaries (API tự áp khi khởi động).
  • Kho lưu trữ (Supabase Storage) phải được cấu hình, vì ghi âm được upload lên đó.
Hai tài khoản phụ huynh: A (chủ hồ sơ) và B (người khác, dùng để test bị chặn quyền). Hai hồ sơ trẻ của A: CON1 và CON2.

2. Sơ đồ thứ tự gọi API

Đi từ trên xuống. Ô viền xanh lam gọi bằng token phụ huynh, ô viền tím gọi bằng token của trẻ. Hai API gửi của trẻ (2a, 2b) không cần theo thứ tự với nhau.

3. Bước 0: tạo dữ liệu nền

Làm tuần tự. Mọi request trừ 0.1 đều cần header Authorization: Bearer PARENT_TOKEN.

POST0.1 Đăng nhập phụ huynh A không cần token

POST {BASE}/api/v1/Auth/login
{
  "identifier": "email-hoac-username-cua-A",
  "password": "mat-khau-cua-A"
}

Lưu data.accessToken → PARENT_TOKEN và data.refreshToken → REFRESH. Làm tương tự để có token của tài khoản B.

POST0.2 Tạo hồ sơ trẻ

POST {BASE}/api/v1/ChildProfile
{ "nickname": "Bé Bin", "ageBand": "Age_6_8", "language": "vi" }

Lưu data.id → CHILD_ID. Tạo thêm hồ sơ CON2 với nickname khác để test phiên đọc của trẻ khác.

POST0.3 Learning Profile

POST {BASE}/api/v1/LearningProfile/{CHILD_ID}
{
  "readingLevel": 2,
  "readingMode": "ListenFirst",
  "comprehensionGoal": "Kể lại được ý chính",
  "topics": [ { "topic": "Động vật", "relation": "FavoriteTopic" } ]
}

POST0.4 Safety Policy: ghi nhận consent và bật giọng nói

POST {BASE}/api/v1/SafetyPolicy/{CHILD_ID}
{
  "maxStoryLength": 2000,
  "parentalGateEnabled": true,
  "consentRecorded": true,
  "voiceAnswersEnabled": true,
  "voiceConsentAccepted": true,
  "categories": []
}
voiceAnswersEnabled: true là điều kiện để trẻ ghi âm được (TC-R02 kiểm tra trường hợp tắt). Để test TC-R02, gọi lại PUT /api/v1/SafetyPolicy/{CHILD_ID} với "voiceAnswersEnabled": false, test xong bật lại.

PATCH0.5 Kích hoạt hồ sơ

PATCH {BASE}/api/v1/ChildProfile/{CHILD_ID}/activate

Kết quả mong đợi: 200, status = "Active". Nếu 400 là còn thiếu Learning Profile hoặc consent.

0.6 Chuẩn bị truyện Ready của CON1

Cần một truyện trạng thái Ready, thuộc CON1 (childProfileId = CON1), có ít nhất 6 cảnh để test giới hạn 5 cảnh. Hai cách:

  • Tạo bằng luồng AI hoặc soạn tay rồi duyệt nội dung và xác nhận media (xem docs/API_FRONTEND_ACTOR_FLOWS.md mục 6, 7).
  • Hoặc dùng truyện đã seed (Database/Seed/11_stories.sql) sau khi chạy Seed-Database.ps1; kiểm tra truyện đó thuộc đúng hồ sơ trẻ bạn dùng.
Nếu truyện chỉ có 1–5 cảnh, vẫn test được mọi case trừ TC-F03 (quá 5 cảnh). Seed mẫu mỗi truyện chỉ có 1 cảnh.

GET0.6b Kiểm tra bé được phép đọc truyện (tùy chọn)

GET {BASE}/api/v1/ChildAccessCredential/story-handover?storyId={STORY_ID}

POST0.7 Cho bé đọc truyện này → lấy CHILD_TOKEN

POST {BASE}/api/v1/ChildAccessCredential/{CHILD_ID}/handover-story
{ "storyId": STORY_ID, "supervisorRefreshToken": "REFRESH" }

Lưu data.accessToken → CHILD_TOKEN. Từ bước này dùng CHILD_TOKEN cho API trẻ.

POST0.8 Mở phiên đọc CHILD_TOKEN

POST {BASE}/api/v1/child/reading/sessions
{ "storyId": STORY_ID }

Lưu data.sessionId → SESSION_ID.

GET0.9 Lấy nội dung để biết id các cảnh CHILD_TOKEN

GET {BASE}/api/v1/child/reading/sessions/{SESSION_ID}/content

Lấy các data.scenes[].sceneId → SCENE_IDS (trường sceneId mới được thêm để API đánh cờ dùng). Có thể gọi thêm POST .../sessions/{SESSION_ID}/complete để phiên ở trạng thái Completed; API tóm tắt dùng được cả khi đang đọc lẫn khi đã xong.

4. API 1: Trẻ gửi ghi âm CHILD_TOKEN

POST/api/v1/child/reading/sessions/{sessionId}/summary/recording

Body: multipart/form-data, một field tên audio (webm, ogg, wav, mp3, m4a hoặc flac), tối đa 3 000 000 byte.

# curl mẫu
curl -X POST "{BASE}/api/v1/child/reading/sessions/{SESSION_ID}/summary/recording" \
  -H "Authorization: Bearer CHILD_TOKEN" \
  -F "audio=@tom-tat.webm;type=audio/webm"

Response thành công:

{ "success": true, "message": "Đã gửi cho bố mẹ", "data": { "summaryId": 1, "message": "Đã gửi cho bố mẹ" } }

Trong Swagger: chọn Try it out, chọn file ở ô audio. Nếu chưa có file thật, ghi âm bất kỳ 5 giây bằng điện thoại và đổi đuôi phù hợp.

Chỉ chủ hồ sơ. Mới nhất trước. pageSize tối đa 50.

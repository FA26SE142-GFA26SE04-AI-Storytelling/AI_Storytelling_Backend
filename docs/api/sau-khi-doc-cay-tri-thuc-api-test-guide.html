1. Chuẩn bị và quy ước

  • Chạy Core API (Swagger ở trang gốc hoặc Postman). Đặt BASE = địa chỉ API, ví dụ http://localhost:5259.
  • Database phải đã áp migration AddKnowledgeTreesAndNotebookRemovedAt (bảng knowledge_trees, cột vocabulary_notebook_entries.RemovedAt).
  • Hai loại token: PARENT_TOKEN (tài khoản User, chủ hồ sơ) và CHILD_TOKEN (token của trẻ). Mọi API của trang này trừ lộ trình đều dùng CHILD_TOKEN; trẻ được lấy từ token, không truyền childProfileId.
  • Mọi response có dạng { "success": ..., "message": ..., "data": ... }. Lỗi nghiệp vụ trả 400/403/404/409 kèm message.
  • Không có API nào ở đây gọi AI. Không trừ lượt tạo truyện.

2. Luật EXP và Cây tri thức

Nguồn EXPCộngKhi nào không cộng
Hoàn thành truyện (POST .../complete)+10Đọc lại truyện đã từng hoàn thành; gọi complete lần hai
Câu quiz đúng (POST /child/quiz/.../answers)+2Câu đó đã từng đúng ở lần nào trước
Lưu từ mới vào Sổ tay (POST /child/notebook/.../words)+1Từ đã có trong sổ; lưu lại từ đã xóa
Tưới cây0Tưới không làm giảm expTotal

Mốc của cây (tính theo EXP đã tưới vào cây đang trồng, currentTreeExp):

SEED · Hạt0 – 29
SPROUT · Mầm30 – 99
SAPLING · Cây non100 – 249
GROWN · Cây lớn250 – 499
FLOWERING · Ra hoa500
  • expToWater = max(0, expTotal − expInvested). Mỗi lần tưới đổ hết số này, nhưng không vượt 500 cho cây hiện tại; phần dư giữ lại.
  • Cây đạt 500 → FLOWERING, được giữ nguyên cho trẻ ngắm. Lần tưới kế tiếp (còn EXP chưa tưới): cây vào vườn (floweredTreeCount + 1), trồng hạt mới và tưới hạt đó (newTreePlanted = true).
  • Cây không reset khi đọc truyện mới, hết lộ trình, bật Hold Mode hay tạm dừng hồ sơ. Không gắn với lộ trình.
  • Huy hiệu: WORD_COLLECTOR_50 khi số từ đang hiện trong sổ đạt 50 ngay sau một lần lưu; ROADMAP_FINISHER khi trẻ đọc xong truyện cuối của lộ trình và không ở Hold Mode (cùng lúc phụ huynh nhận RoadmapCompleted). Mỗi huy hiệu nhận một lần.

4. Sơ đồ API giao tiếp với nhau

API nào gọi service nào, service ghi vào bảng nào. Nét cam là ghi dữ liệu. Điểm quan trọng: các API kiếm EXP chỉ ghi achievements.ExpTotal; API tưới cây chỉ đọc ExpTotal và chỉ ghi bảng knowledge_trees, nên hai việc chạy cùng lúc không ghi đè nhau.

5. Bước 0: tạo dữ liệu nền

Làm tuần tự. Các bước 0.1–0.4 dùng PARENT_TOKEN, từ 0.5 dùng CHILD_TOKEN.

POST0.1 Đăng nhập phụ huynh không cần token

POST {BASE}/api/v1/Auth/login
{
  "identifier": "email-hoac-username",
  "password": "mat-khau"
}

Lưu data.accessToken → PARENT_TOKEN, data.refreshToken → REFRESH.

0.2 Hồ sơ trẻ Active

Dùng hồ sơ đã Active, hoặc tạo mới theo thứ tự: POST /api/v1/ChildProfile → POST /api/v1/LearningProfile/{CHILD_ID} → POST /api/v1/SafetyPolicy/{CHILD_ID} (có "consentRecorded": true) → PATCH /api/v1/ChildProfile/{CHILD_ID}/activate. Body mẫu xem docs/api/story-summary-api-test-guide.html bước 0.2–0.5.

Hồ sơ trẻ mới tạo chưa có dòng trong achievements và knowledge_trees. Đây là trạng thái tốt nhất để test từ đầu.

POST0.3 Thêm truyện vào lộ trình (chỉ cần cho API 5) PARENT_TOKEN

POST {BASE}/api/v1/ChildRoadmap/stories
{
  "storyId": STORY_A,
  "childProfileIds": [ CHILD_ID ],
  "position": "End"
}

Kiểm tra: GET {BASE}/api/v1/ChildRoadmap/{CHILD_ID} có đúng 1 bước Open là STORY_A.

POST0.4 Mở phiên trẻ → CHILD_TOKEN PARENT_TOKEN

POST {BASE}/api/v1/ChildAccessCredential/{CHILD_ID}/handover
{ "supervisorRefreshToken": "REFRESH" }

Lưu data.accessToken → CHILD_TOKEN.

POST0.5 Mở phiên đọc CHILD_TOKEN

POST {BASE}/api/v1/child/reading/sessions
{ "storyId": STORY_A }

Lưu data.sessionId → SESSION_ID.

GET0.6 Lấy nội dung → id từ vựng CHILD_TOKEN

GET {BASE}/api/v1/child/reading/sessions/{SESSION_ID}/content

Lấy hai giá trị data.vocabulary[].id → VOCAB_1, VOCAB_2.

GET0.7 Lấy quiz CHILD_TOKEN

GET {BASE}/api/v1/child/quiz/sessions/{SESSION_ID}

Lấy một quizItemId → QUIZ_ITEM. Trả lời đúng một câu để có +2 EXP:

POST {BASE}/api/v1/child/quiz/sessions/{SESSION_ID}/answers
{ "quizItemId": QUIZ_ITEM, "answer": "dap-an-dung" }

0.8 Câu SQL hỗ trợ (chỉ DB local / test)

Dùng để test mốc ra hoa và 50 từ mà không phải đọc hàng chục truyện. Không chạy trên DB dùng chung hay production.

-- Cho trẻ có 520 EXP (tạo dòng nếu chưa có)
INSERT INTO achievements ("ChildProfileId","ExpTotal","StreakDays","CreatedAt","IsDeleted")
VALUES (CHILD_ID, 520, 0, NOW(), false)
ON CONFLICT ("ChildProfileId") DO UPDATE SET "ExpTotal" = 520;

-- Xem trạng thái cây
SELECT * FROM knowledge_trees WHERE "ChildProfileId" = CHILD_ID;

-- Đếm từ đang hiện trong Sổ tay
SELECT COUNT(*) FROM vocabulary_notebook_entries
WHERE "ChildProfileId" = CHILD_ID AND "RemovedAt" IS NULL AND NOT "IsDeleted";
Muốn test WORD_COLLECTOR_50 bằng SQL: chèn 49 dòng vocabulary_notebook_entries cho CHILD_ID với các StoryVocabularyId có thật (khác VOCAB_1), rồi gọi API 3 với VOCAB_1. Bảng có unique (ChildProfileId, StoryVocabularyId), nên mỗi dòng phải là một từ khác nhau.

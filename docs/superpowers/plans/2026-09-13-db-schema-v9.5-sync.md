# Đồng bộ DB Schema lên v9.5 (DBML mới) — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Đưa schema EF Core (`StoryPlatform.Domain` + `StoryPlatform.Infrastructure`) và `Database/Seed-Database.ps1` khớp với đặc tả DBML v9.5 (`ai_storytelling_platform`) do người dùng cung cấp — thêm 7 bảng mới, thêm cột mới vào ~11 bảng hiện có, mở rộng 3 enum, xử lý 1 breaking change (`o2o_assessments`), sinh migration mới, và cập nhật seed data.

**Architecture:** Giữ nguyên kiến trúc Clean Architecture hiện có (`Domain.Entities` là POCO kế thừa `BaseEntity`; `Infrastructure.Persistence.Configurations` chứa `IEntityTypeConfiguration<T>` cho từng entity, tự động áp dụng qua `modelBuilder.ApplyConfigurationsFromAssembly`; `ApplicationDbContext` khai báo `DbSet<T>` thủ công). KHÔNG đổi pattern nào — chỉ thêm entity/cột mới theo đúng convention đã có. Không xoá cột/bảng cũ nào không có trong DBML (theo yêu cầu người dùng: "giữ nguyên" phần cũ), trừ 2 cột bị breaking change ở `o2o_assessments` (có backfill trước khi drop).

**Tech Stack:** .NET 8, EF Core (Npgsql provider), PostgreSQL, PowerShell (`psql.exe`) cho seed script.

**Spec:** DBML `ai_storytelling_platform` v9.5 do người dùng dán trong yêu cầu gốc (không có file vật lý trong repo — nội dung đầy đủ nằm trong lịch sử hội thoại; các Task dưới đây trích dẫn lại phần liên quan của DBML cho từng bảng/cột).

## Global Constraints

- KHÔNG xoá bất kỳ cột/bảng nào đang tồn tại trong entity hiện có, trừ `O2OAssessment.AssignmentId` / `O2OAssessment.ChildProfileId` (breaking change đã được người dùng xác nhận áp dụng đúng DBML, có backfill).
- Mọi entity mới kế thừa `BaseEntity` (`Id`, `CreatedAt`, `UpdatedAt`, `IsDeleted`) — khớp pattern hiện có, kể cả khi DBML gốc không có `IsDeleted`/`UpdatedAt` cho bảng đó (soft-delete là convention nội bộ của dự án).
- Mọi enum mới đặt tên PascalCase không hậu tố `Enum` (khớp convention: DBML `org_verification_enum` → C# `OrgVerification`).
- Mọi FK dùng `OnDelete(DeleteBehavior.Restrict)` trừ khi entity hiện có đã dùng hành vi khác (kiểm tra file cấu hình liền kề trước khi viết).
- Mọi cột enum lưu dưới dạng string (`HasConversion<string>().HasMaxLength(N)`) — khớp convention hiện có (`SupervisionInvitationConfiguration`, `O2OAssessmentConfiguration`, v.v.).
- Migration đặt tên theo thứ tự thời gian sau migration cuối cùng đã có: `AddRefreshAndEmailVerificationTokens` (2026-09-12). KHÔNG áp dụng migration vào database thật trong phạm vi plan này (người dùng đã chọn "chỉ sinh code/migration, tự áp dụng sau").
- Seed script (`Database/Seed-Database.ps1`) giữ nguyên toàn bộ 48 bảng insert hiện có; chỉ (a) bổ sung cột mới vào các câu `INSERT` đang có, (b) thêm block `INSERT` mới cho 7 bảng mới, (c) thêm tên 7 bảng mới vào mảng `tables` ở bước reset sequence cuối file, (d) cập nhật số đếm/summary trong comment (`-- N. table (10)`).
- Tổng số bảng seed sau khi hoàn tất: 48 → 55.

using Microsoft.EntityFrameworkCore;
using Microsoft.EntityFrameworkCore.Metadata.Builders;
using StoryPlatform.Domain.Entities;

namespace StoryPlatform.Infrastructure.Persistence.Configurations;

public class RefreshTokenConfiguration : IEntityTypeConfiguration<RefreshToken>
{
    public void Configure(EntityTypeBuilder<RefreshToken> builder)
    {
        builder.ToTable("refresh_tokens");

        builder.HasKey(x => x.Id);

            .OnDelete(DeleteBehavior.Restrict);

        builder.HasIndex(x => x.TokenHash)
            .IsUnique();

        builder.HasQueryFilter(x => !x.IsDeleted);
    }
}

4. Stale Result Detection & Freshness Checks

sequenceDiagram
    autonumber
    participant MG as MediaGenerationService
    participant DB as Database

    Note over MG,DB: AssertFresh: Kiểm tra trước mỗi persist

    MG->>DB: RequireClaimedJob(jobId, token)
    DB-->>MG: Job (with current ConcurrencyToken)

    MG->>DB: Get Story(job.StoryId)
    alt Story status changed
        DB-->>MG: Story.Status != MediaProcessing
        MG->>MG: throw InvalidOperationException("STALE_MEDIA_RESULT")
    end

    MG->>DB: Get StoryVersion(job.StoryVersionId)
    alt Version not current
        DB-->>MG: Version.IsCurrent == false
        MG->>MG: throw InvalidOperationException("STALE_MEDIA_RESULT")
    end

    MG->>DB: Get latest MediaContext
    alt Context changed/deleted
        DB-->>MG: Context.Id != expected
        MG->>MG: throw InvalidOperationException("STALE_MEDIA_RESULT")
    end

    Note over MG,DB: Freshness validated - proceed with persist

    MG->>DB: Save changes
    MG->>DB: CommitTransaction

6. Scene Coverage Validator Logic

sequenceDiagram
    autonumber
    participant C as Caller (MediaGenerationService)
    participant V as SceneCoverageValidator
    participant B as StoryBlock (from Parser)

    C->>V: ValidateAndAssemble(content, blocks, selections)

    Note over V: 1. Verify block coverage
    loop For each SceneSelection
        V->>V: Verify all BlockIds exist in blocks
        V->>V: Verify blocks are in ascending order
        V->>V: Verify blocks are contiguous
        alt Block missing
            V->>V: throw "MISSING_BLOCK"
        end
        alt Out of order
            V->>V: throw "OUT_OF_ORDER_BLOCKS"
        end
        alt Non-contiguous
            V->>V: throw "NON_CONTIGUOUS_BLOCKS"
        end
    end

    Note over V: 2. Verify no duplicates
    V->>V: Collect all BlockIds across scenes
    alt Duplicate BlockId found
        V->>V: throw "DUPLICATE_BLOCK"
    end

    Note over V: 3. Verify complete coverage
    alt Not all blocks assigned
        V->>V: throw "INCOMPLETE_COVERAGE"
    end

    Note over V: 4. Assemble StoryScenes
    loop For each SceneSelection
        V->>V: Calculate TextRangeStart from first block
        V->>V: Calculate TextRangeEnd from last block
        V->>V: Extract SceneText from content
        V->>V: Generate VisualDescription
        V->>V: Create StoryScene record
    end

    V-->>C: List<StoryScene> (validated)

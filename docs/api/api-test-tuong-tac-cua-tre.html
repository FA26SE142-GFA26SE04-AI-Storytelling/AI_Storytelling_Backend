API và test case — Tương tác của trẻ

AI Storytelling Backend · Tương tác lúc nghe (P6): trẻ nhận tương tác theo scene, bật "Chỉ nghe", gửi câu trả lời; phụ huynh xem câu trả lời cảm xúc/cảm nhận. Mỗi API có giải thích, body ví dụ và test case kèm đầu vào / đầu ra. Tích vào ô để đánh dấu đã chạy (lưu trong trình duyệt).

Quy ước chung

Cách gọi

  • Địa chỉ gốc: http://localhost:5259/api/v1/.... Mọi phản hồi bọc trong ApiResponse: { "success", "message", "data", "errors" }.
  • Đính kèm Authorization: Bearer {accessToken}. API dưới /api/v1/child/reading chỉ nhận token trẻ (policy ChildSession); token phụ huynh bị từ chối.
  • Lỗi nghiệp vụ trả qua ExceptionHandlingMiddleware: { "success": false, "message": "<mã hoặc thông báo>", "data": null, "errors": null }.
  • Mã lỗi thường gặp: 400 LISTENING_ANSWER_INVALID, 401 chưa đăng nhập, 403 sai loại token / phiên bị ngắt / truyện chưa mở, 404 phiên hoặc tương tác không có, 409 LISTENING_SESSION_CLOSED.
  • Đầu ra trong bảng test chỉ ghi phần data, trừ khi ghi rõ là toàn bộ response. URL audio / ảnh rút gọn bằng …; khi chạy thật có thể là URL đã ký.

Dữ liệu thật trong Database/Seed (nạp bằng Seed-Database.ps1)

  • Mật khẩu mọi tài khoản demo: Demo@123. Phụ huynh đăng nhập bằng POST /api/v1/Auth/login với { "identifier": "parent_demo1", "password": "Demo@123" }.
  • parent_demo1 (id 2) là Owner bé 1 (6-8 tuổi). parent_demo2 (id 3) không phải Owner bé 1 (dùng cho test quyền).
  • Bé 1 đăng nhập bằng POST /api/v1/ChildAccessCredential/easylogin/login với { "secret": "demo-qr-child-01" }.
  • Truyện 900 "Thỏ con đi lạc": truyện AI của parent_demo1 cho bé 1, 6 đoạn, version 900, có đủ 5 tương tác (seed 11_stories, 13_story_versions, 60_listening_interactions, 61_listening_interaction_options).
  • Tương tác và scene:
    • Scene 0 · 900 Checkpoint (Emotion) · thẻ 900 Thỏ đang sợ, 901 Thỏ đang vui, 902 Thỏ đang buồn ngủ, 903 Thỏ đang tò mò.
    • Scene 1 · 902 RolePlay · nhân vật Thỏ, câu mẫu "Có ai ở đó không?".
    • Scene 2 · 901 Checkpoint (Prediction) · thẻ 904 Bác Gấu tốt bụng, 905 Một cơn gió mạnh.
    • Scene 3 · 903 PicturePrediction · thẻ 906 Mẹ Thỏ, 907 Một bạn sóc nhỏ · đáp án lộ ở scene 4.
    • Scene 4 · không có tương tác.
    • Scene 5 (cuối) · 904 EventOrdering · thẻ 908 Thỏ đi lạc vào rừng (câu ở scene 0), 909 Bác Gấu đến giúp Thỏ (scene 2), 910 Thỏ biết nhờ người lớn giúp (scene 5). Thứ tự đúng 908 → 909 → 910.
  • Điều kiện trước: seed để truyện 900 ở trạng thái chờ duyệt. Trẻ chỉ đọc được khi truyện đã duyệt (P4-31) và có media (Phase 5 thật, hoặc media giả ở mục 0b Bước 7) — xem hướng dẫn P1–P6.
  • Lưu ý: nhiều test đổi trạng thái (lưu attempt, đóng phiên). Chạy theo thứ tự trong trang; muốn chạy lại từ đầu thì mở phiên mới hoặc nạp lại seed.

       "Provider", "StorySceneId", "StorySegmentId", "Url", "LastValidationReason"

Nhóm 4 · Luyện đọc ASR (Luồng 3 mục 4)

Trẻ đọc to một đoạn truyện; backend gửi âm thanh sang Google Speech-to-Text, so khớp từng chữ với đoạn truyện và trả về good / retry / skipped. Không lưu âm thanh, không chấm điểm, không giới hạn lượt. Dùng phụ huynh parent3@example.com, bé 6, truyện 6, đoạn 6: "Sau lớp sóng biển xanh là cả một thế giới kỳ diệu..." (12 chữ).

File ghi âm cần chuẩn bị (định dạng .wav, .mp3 hoặc .webm, dưới 1 MB): (1) đọc đúng cả câu; (2) đọc cả câu nhưng đọc "sóng" thành "song"; (3) chỉ đọc "Sau lớp sóng biển xanh". Có thể ghi bằng điện thoại hoặc Audacity rồi xuất WAV/MP3. File .m4a (mặc định của Windows Sound Recorder) có thể Google không đọc được, nên đổi sang WAV/MP3 trước.
TC28

Bật Cloud Speech-to-Text API

Kiểm tra

Việc làm một lần trên Google Cloud, cho cả nhóm. Không bật thì mọi lần luyện đọc đều trả 503.

Cách bật

Google Cloud Console → project "Ai Storytelling" → APIs & Services → Library → "Cloud Speech-to-Text API" → Enable. Hoặc chạy:

gcloud services enable speech.googleapis.com --project=gen-lang-client-0675088605
Trang API hiện trạng thái Enabled. Sau đó khởi động lại Core.
Nếu chưa bật mà vẫn gọi TC32, API trả HTTP 503 với message = "Micro đang bận một chút, em đọc tiếp truyện nhé." Đây là hành vi đúng khi Google không dùng được.

TC41

Kiểm tra không lưu âm thanh, chỉ lưu số đếm

Kiểm tra

Chạy trong pgAdmin hoặc psql, database AIStorytellingDB.

SQL Câu lệnh
SELECT "ReadingSessionId", "EventType", "EventPayload", "OccurredAt"
FROM telemetry_logs
WHERE "EventType" = 'AsrWordResult'
ORDER BY "Id" DESC
LIMIT 10;
  • Mỗi lần gọi thành công (TC32–TC34) có đúng một dòng; các lần lỗi (TC35–TC40) không tạo dòng nào.
  • EventPayload chỉ có số đếm, ví dụ {"segmentId":6,"total":12,"good":11,"retry":1,"skipped":0}; không có lời trẻ nói, không có âm thanh.
  • Supabase Storage, bucket story-media: không có file mới sau các lần luyện đọc.
Tính năng audio phát âm từ vựng (migration AddVocabularyAudio) và luyện đọc ASR (POST …/read-aloud). Dấu "Đạt" chỉ lưu trên trình duyệt của bạn.
